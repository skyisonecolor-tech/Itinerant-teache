# 순회교사 배치 도우미

관내 중학교 순회교사(교과 시수 교환) 배치를 돕는 단일 HTML 웹앱입니다.

## GitHub Pages로 사용하기
1. 저장소에 `index.html`을 올립니다.
2. 저장소 **Settings → Pages**에서 `main` 브랜치 `/ (root)`를 선택합니다.
3. 안내되는 주소(`https://아이디.github.io/저장소명/`)로 접속합니다.

## 사용 순서
1. 오른쪽 위 ⚙(설정)에서 학년도·학기 선택, 학교·권역·교과 확인
2. 설정에서 엑셀 업로드
   - 순회교사 요청 현황 (순회 요청 현황 / 순회 지원(희망) 현황 양식)
   - 학교별 수업시수: 설정의 「학교별 수업시수 자료」에서 학교마다 엑셀·PDF·이미지(화면 캡처 1장)를 올림
     (이미지·스캔 PDF는 브라우저 안에서 글자 인식 후 확인 단계를 거쳐 반영, 교사수는 기준년도 정원(B))
     「여러 파일 한꺼번에 올리기」: 파일명에 학교명이 있으면 자동 매칭 (예: 군자중학교_수업시수.xlsx)
3. 요청 현황과 수업시수 자료가 모두 올라가면 설정을 닫을 때 **자동으로 배치**됩니다.
   - 「↻ 재작업」: 같은 수준의 다른 배치안으로 바꿉니다 (직접 수정한 칸은 유지)
   - 칸을 누르면 교과·시수를 **골라서** 넣거나 고칠 수 있습니다
4. **출력·다운로드** 탭 → 전체 운영계획(B4 1장) 또는 학교별(A4 학교당 1장) 인쇄, 엑셀 다운로드(전체 + 학교별 시트)

## 배치 원칙
- 시수는 있으나 교사가 없는 교과 요청을 가장 먼저 배정
- 지원교는 해당 교과 평균시수(시수÷교사수) 17 이하인 학교만, 지원 후 평균 18.5 이하 (설정에서 변경 가능)
- 같은 권역 우선 → 맞교환 가능 → 지원 희망 → 이동시간 짧은 순
- 순환은 5개교까지 (2개교 맞교환 우선)
- 1건(한 학교로 가는 한 번의 방문) 최소 2시간 이상 배정
- 한 학교가 순회를 나가는 학교는 최대 3곳
- 시수가 딱 맞지 않으면 쪼개지 않고 요청보다 ±2시간(요청의 1/3 이내) 더 받거나 덜 받도록 조정 (교사 0명 교과는 정확히)
- 위 수치는 설정의 「배치 원칙」에서 바꿀 수 있음
- 「참여 제한」 학교(기본: 군서미래국제학교)는 다른 방법이 없을 때만 배정
- 「자율」은 어느 교과에서 오든 무관하므로 평균시수 원칙을 적용하지 않음
- 원칙을 벗어난 배정은 화면에서 ⚠ 표시 + 메모 (출력·엑셀에는 표시 안 됨)

## 이동시간
설정 → 「위치 찾기 + 이동시간 측정」을 누르면 브라우저에서 OpenStreetMap(Nominatim)으로 학교 위치를,
OSRM 공개 경로 서버로 자동차 이동시간을 계산합니다. 못 찾은 학교는 주소나 좌표를 직접 넣을 수 있습니다.

## 참고
- 작업 내용은 브라우저(localStorage)에 자동 저장됩니다. 다른 PC에서 이어서 하려면 설정의 「작업 파일 저장」 → 다른 PC에서 「작업 파일 불러오기」.
- 엑셀 읽기: SheetJS 0.18.5, 엑셀 쓰기: ExcelJS 4.4.0, PDF: pdf.js 3.11.174, 글자 인식: Tesseract.js 5.1.1 (모두 CDN, 필요할 때만 불러옴)
